# Общий код

Это часть описания [архитектуры `app`](README.md). Общий код это инструменты, которые нужны нескольким слоям и не знают ни про один виджет: тексты интерфейса, тема, геометрия окна, раскладка клавиш и команды, ввод-вывод общего назначения.

## Как понять, что код относится к общему коду

Код кладут в общий код, когда он нужен нескольким слоям и при этом:
- не принадлежит одному виджету, иначе он лежит в этом виджете;
- не описывает понятие предметной области, иначе он лежит в [домене](domain.md);
- не доставляет события, не выполняет эффекты и не собирает окно, иначе это [приложение](app.md), [эффекты](effects.md) или [экраны](screens.md).

Вот какой код сейчас лежит в общем коде. Это примеры, а не полный список:

| Что | Примеры |
| --- | --- |
| тексты интерфейса | ключи перевода, файлы локалей, подстановка ошибки в шаблон |
| внешний вид | темы, шрифты, иконки |
| размещение в окне | где открыть контекстное меню, где лежит основная область |
| клавиатура и команды | раскладка клавиш, `AppCommand`, фокус, который не принадлежит ни одному виджету |
| ввод-вывод общего назначения | имя компьютера, открытие ссылки в браузере, файлы интеграции shell |

Что лежит в конкретном модуле, описывает его комментарий в коде.

## Что общий код может импортировать

Общий код импортирует только другой общий код, [домен](domain.md) и крейты. Приложение, эффекты, экраны и виджеты он не импортирует никогда. Поэтому общим кодом может пользоваться любой слой. Полная таблица лежит в разделе [«Кто что импортирует»](README.md#кто-что-импортирует).

## Модули ввода-вывода

Модули ввода-вывода это часть общего кода, которая обращается во внешний мир: к файлам и процессам. Сейчас это `services.rs` и `shell_integration.rs`. Среди общего кода только у них снят запрет clippy на такие вызовы: `#[expect(clippy::disallowed_methods, reason = "...")]` стоит на их объявлении.

Ими пользуются только:
- [эффекты](effects.md);
- `services.rs`, `storage.rs` и `subscription.rs` виджетов и дочерних виджетов;
- сами модули ввода-вывода, друг у друга.

Остальной общий код ввод-вывод не выполняет и модулями ввода-вывода не пользуется. Например, сессию, с которой стартует новая вкладка терминала, общий код только собирает, а файлы интеграции shell к ней добавляет модуль ввода-вывода, который вызывают эффекты, например [эффекты запуска](effects.md#эффекты-запуска).

## Куда класть общий код

| Что нужно | Куда положить |
| --- | --- |
| тип, нужный двум виджетам | [домен](domain.md), если это понятие предметной области, иначе общий код |
| элемент интерфейса | нужен нескольким виджетам: компонент в `otty-ui-kit`; одному: его `view/`. Слоя для общих элементов интерфейса в `app` нет |
| новый текст | `i18n/key.rs` и файлы локалей |
| действие для шортката, палитры или кнопки шапки | вариант `AppCommand` и, для шортката, вариант `AppShortcut`, см. [«Команды»](app.md#команды) |
