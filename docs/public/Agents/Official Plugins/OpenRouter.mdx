Built into OTTY · version 0.1.0 · `github.com/otty-shell/otty-plugin-openrouter`

| Part       | Kind     | Gives                                                  |
| ---------- | -------- | ------------------------------------------------------ |
| OpenRouter | provider | **Key limit**: how much of the key's limit was used.   |

| Request                                  | With                         | When                                 |
| ---------------------------------------- | ---------------------------- | ------------------------------------ |
| `GET https://openrouter.ai/api/v1/key`   | The key in `Authorization`. | Every read of the account's numbers. |

The keys it gets, only as handles:

- a key you add: **Add account** → OpenRouter, with a file that holds it or an environment variable;
- a key an agent part found for `openrouter.ai`, such as the key of a Claude Code profile whose
  `ANTHROPIC_BASE_URL` is `https://openrouter.ai/api`, or an OpenRouter key of OpenCode.

OpenRouter does not tell whose account a key is, so OTTY knows the account by the key's fingerprint.
It reads no files and runs nothing. With no OpenRouter key found, it does nothing.

**Open usage page** opens `openrouter.ai/activity`. Its icon is a letter icon until a logo that may
be shipped is found.
