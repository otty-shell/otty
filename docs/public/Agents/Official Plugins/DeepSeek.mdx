Official · version 0.1.0 · install it from `assets/plugins/deepseek/` of the OTTY repository with
**Add plugin from folder…** ([how](../../plugins/#install-the-official-plugins)); its own
repository will be `github.com/otty-shell/otty-plugin-deepseek`

| Part     | Kind     | Gives                                  |
| -------- | -------- | -------------------------------------- |
| DeepSeek | provider | **Left**: the money left on the account. |

| Request                                    | With                         | When                                  |
| ------------------------------------------ | ---------------------------- | ------------------------------------- |
| `GET https://api.deepseek.com/user/balance` | The key in `Authorization`. | Every read of the account's numbers.  |

The keys it gets, only as handles:

- a key you add: **Add account** → DeepSeek, with a file that holds it or an environment variable;
- a key an agent part found for `deepseek.com`, such as the key of a Claude Code profile whose
  `ANTHROPIC_BASE_URL` is `https://api.deepseek.com/anthropic`, or a DeepSeek key of OpenCode.

DeepSeek does not tell whose account a key is, so OTTY knows the account by the key's fingerprint.
It reads no files and runs nothing. With no DeepSeek key found, it does nothing.

**Open usage page** opens `platform.deepseek.com/usage`. Its icon is a letter icon until a logo that
may be shipped is found.

## What it asks you for

The need carries the label "DeepSeek plugin". Its texts come in all ten languages of OTTY.

| Need                | When                                    | Button |
| ------------------- | --------------------------------------- | ------ |
| The key was refused | DeepSeek refused the key of an account you added with **Add account**. | **DeepSeek key…**: the field of the key, with the file or variable of the old one. Make a new key on `https://platform.deepseek.com/api_keys` (the field's button opens it) and give its file or variable; it takes the old one's place, and the account is read again with it. |
| The key was refused | DeepSeek refused a key an agent keeps, such as one in OpenCode's settings. | **Open platform.deepseek.com**: `https://platform.deepseek.com/api_keys`, where you make a new key. Put it where the agent keeps the old one. |

It asks for no key of its own: a key no agent uses is added with **Add account**.
