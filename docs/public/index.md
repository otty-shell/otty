# OTTY documentation

## Getting started

Install OTTY in one of three ways:

- [Binary package](./getting-started/installation/binary/): download and install, the quickest way.
- [Package managers](./getting-started/installation/package-managers/): Homebrew on macOS, pacman on
  Arch Linux; updates come with your system.
- [From source](./getting-started/installation/from-source/): build it yourself, with the packages
  each system needs.

## Agents

- Providers: [Claude Code](./agents/providers/claude-code/) and [Codex](./agents/providers/codex/),
