# otty-app-explorer

The explorer feature of the OTTY app without I/O: its state, decisions and
views. It shows the folder of the active terminal as a tree, with a context
menu, a name field, a delete dialog and drag and drop to change its files.
The folder reads, the file changes and the file watch live in
`otty-app-explorer-io`.

It fills the right panel (the Files section in Terminal mode). It must not
read the disk itself.
